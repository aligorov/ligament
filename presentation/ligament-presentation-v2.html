02

Почему self-hosted MFA нужен сейчас

Данные в контуре

Секреты не покидают сервер

Облачные MFA-сервисы хранят пользователей и логи входов у вендора. Ligament целиком разворачивается в вашем Docker: БД, аудит, мастер-ключ — ваши.

Импортонезависимость

Без внешних зависимостей

Не нужен доступ к зарубежным облакам. Сервер, приложение и провайдеры доставки (SMTP/SMS/Telegram) настраиваются на любые российские сервисы.

Стоимость

Прозрачная модель

Бесплатно до 5 пользователей бессрочно, демонстрация по подписанному файлу, подписка или разовая бессрочная лицензия — без пер-юзерных облачных тарифов.

Один администратор разворачивает Ligament за 10 минут: docker compose → админка → подключение сетевого оборудования, RDP и приложений. Русскоязычная веб-панель, все настройки в базе — без правки env-файлов.

04

Факторы и каналы подтверждения

Push + number matching

Подтверждение входа с вводом контрольного числа — защита от push-fatigue атак. Число показывается на самом экране входа (RDP-тайл, веб).

TOTP и резервные кодs

Классические 6-значные коды (совместим с Google Authenticator), одноразовые коды восстановления, защита от переигрывания.

Passkeys / WebAuthn

Беспарольный вход и аппаратные ключи (YubiKey) в вебе и на тайле Windows — FIDO2-церемония прямо на экране входа.

Telegram

Бот: коды, push-подтверждения одной кнопкой, привязка аккаунта, уведомления о входах.

Email и SMS

Настраиваемые шаблоны с подстановками; SMS-пресеты российских шлюзов; сообщения на языке получателя.

Гибкие политики

Предпочтительные каналы на пользователя и группу, TTL кодов, лимиты попыток, пер-юзерная блокировка брутфорса.

05

RADIUS: Wi-Fi 802.1X, VPN, сетевое оборудование

Методы и удержание push

PAP и EAP-TTLS/PAP — «пароль + код» в одном поле; PEAP/MS-CHAPv2 — для нативных supplicant'ов. Push-удержание: NAS ждёт подтверждения из приложения.

Окно доверия устройств

После успешного 2FA повторные подключения без второго фактора. Настраивается на пользователя и на группу (дней), глобально — выключено.

Любое RADIUS-оборудование

UniFi, MikroTik, Cisco, Fortinet и любой NAS: Vendor-Specific Attributes, Accounting, ротация секрета без простоя, Message-Authenticator по RFC 3579.

Защита периметра

Rate-limit на пакет, пер-юзерные счётчики неудач, fail2ban-механика без самобана маршрутизатора, чёрные/белые списки IP.

Сценарий: корпоративный Wi-Fi и VPN без пароль-спамства — пользователь подтверждает вход в приложении раз в заданное окно, остальные подключения проходят по доверию.

06

Windows Credential Provider: 2FA на RDP и консоли

Родной тайл входа

Собственный провайдер для LogonUI: логин + пароль + второй фактор прямо на экране RDP. Независимые флаги для RDP-сессий и физической консоли.

Number matching на тайле

Контрольное число отображается на экране входа — подтверждение только с ним. Fail-close по политике: сервер недоступен → вход запрещён.

FIDO2 прямо на тайле

WebAuthn-церемония на экране входа: аппаратные ключи/YubiKey. Загрузка webauthn.dll по явному пути System32.

Доставка и управление

MSI-установщик с параметром SERVERURL, .reg-шаблоны, GPO-политики в реестре, bypass-список аварийных учёток, файл-диагностика cp.log.

Модель учёток: пользователь Ligament и локальная Windows-учётка совпадают именем и паролем — сервер решает, достаточно ли факторов, вход физически выполняет Windows. Подмена входа невозможна.

SSO и каталоги
07

Встроенный IdP: OpenID Connect и LDAP/AD

OIDC Provider в ядре

Discovery, JWKS, ID-токены RS256, PKCE для публичных клиентов, consent-страница, userinfo — без отдельного Keycloak. Подключение приложений за минуты из админки.

LDAP / Active Directory

Bind-проверка пароля в каталоге, автопровижининг с учётом лимита лицензии, синк групп/ролей/email/телефона, ограничение по группам AD, синхронизация блокировок учёток.

Сессии и устройства

Веб-сессии и доверенные устройства, скользящий TTL device-токенов, отзыв устройств из админки, аудит всех входов.

Честные границы

SAML-провайдера нет (только OIDC); SCIM-провижининга нет — синк выполняется при входе пользователя.

Мультиязычность: язык следует за платформой

Дефолт — системный язык

Веб — язык браузера/ОС (Accept-Language), приложение — локаль устройства, тайл Windows — язык Windows (MUI). Ручной выбор перекрывает всегда.

Все поверхности

Админка, страницы входа, консент, статусы и ошибки; приложение — экраны, approval-модалки, поддержка; email/SMS/Telegram — язык получателя.

Волна 1

en, es, pt-BR, de, fr, zh, tr + русский. Единый словарь терминов; контракт «ключ есть во всех языках» проверяется сборкой.

Для интеграций: международная компания получает интерфейс на языке ОС каждого сотрудника — без настроек и без отдельных сборок под язык.

Встроенная поддержка (SOS): вход решается без админа сервера

1 · ПользовательПотерял телефон → кнопка «Обращение» прямо на экране входа (без аутентификации)
→
2 · ОператорБерёт заявку из очереди, вводит контрольное число с экрана пользователя
→
3 · СессияЧат + WebRTC-просмотр экрана (view-only, без управления), передача файлов
→
4 · ИтогПроблема решена, обращение закрыто — сервер не тронут

Защита от соц-инжиниринга

Соединение — только по контрольному числу с экрана заявителя: максимум 3 попытки, ошибка гасит заявку. Подключиться «за чужого» нельзя.

Категории и эскалация

Роли операторов IT / 1С: инженер 1С не попадает в IT-обращения. Передача коллеге с сохранением истории. Аудит всех действий.

Жёсткие рамки

Одна активная заявка на пользователя, заявка без движения гаснет через 15 минут, сессия — не дольше 4 часов. Жизненный цикл валидирует FSM в БД.

Для сервис-компаний: white-label брендинг + консоль поддержки = ваша техподдержка прямо в окне входа клиента — без AnyDesk/TeamViewer и без доступа к серверу.

10

Инженерная база: независимый аудит, всё закрыто

Криптография

argon2id для паролей, AES-256-GCM с AAD-привязкой, Ed25519-лицензии, constant-time сравнения, crypto/rand во всех токенах.

Отказоупорство входа

Rate-limit по корзинам (IP/юзер/челлендж), fail2ban с окнами и банами, per-user блокировки, расход попыток на number-matching.

Изоляция назначений

Коды строго по purpose, одноразовость челленджей и OIDC-кодов на уровне БД, защита от replay TOTP, изоляция каналов подтверждения.

Аудит и наблюдаемость

Полный журнал входов/отказов/админ-действий с ретеншном, health-check, структурные логи, диагностика Credential Provider.

Web-защита

Строгая CSP (рекламная — только на страницах со слотами), CSRF на всех формах, защита от open-redirect, экранирование контента.

Независимый аудит

15 ревьюеров по подсистемам: 2 критические уязвимости (обход 2FA через app-токен, порча restore) и ~25 важных замечаний — закрыты в релизах v0.4.70+.

Лицензирование: офлайн — и защита от копирования

Режимы сегодня

Free — до 5 пользователей бессрочно; Demo — до 30 дней по подписанному файлу; Subscription — до 13 месяцев + grace; Perpetual — бессрочная с окном обновлений. Все проверки локально, без phone-home.

Дистрибуция

Docker Hub (multi-arch), GitHub Releases для клиентов (MSI, RDP-пакет, APK, DMG, IPA), генерация лицензий вендором, CRL-отзыв. Генератор лицензий не попадает в клиентские сборки.

Роадмап v0.4.78 — защита от копирования

Код активации по железу (machine-id/VM-UUID) → персональная лицензия; редакции по фичам (SSO / LDAP / поддержка / доверие); отдельное Docker-приложение Licensier: выдача, реестр, отзыв. Привязка демо — галкой, старые лицензии совместимы.

Для системных интеграторов

White-label + SOS-консоль = готовый продукт под вашей маркой; лицензия ограничивает только число пользователей и набор фич.

Где Ligament выигрывает — и где нет

Сильные стороны

  • Полный self-hosted без облака вендора — изолированный контур из одного контейнера.
  • Free-тариф до 5 пользователей — рабочий продукт, а не триал.
  • Wi-Fi/VPN/RDP из коробки — окно доверия per-user/group, number matching на тайле, FIDO2, VSA, Accounting.
  • Встроенные OIDC IdP и support-консоль — не нужно докупать Keycloak и remote-assistant.
  • Мультиязычность — интерфейс на языке ОС пользователя, 8 языков.
  • White-label и офлайн-лицензирование — продукт под вашей маркой, без phone-home.

Честные ограничения

  • Нет сертификатов ФСТЭК/ФСБ — для гос-сектора и КИИ обязательны сертифицированные аналоги (IDEA MFA, ViPNet IAS, UserGate).
  • Нет SAML и SCIM — интеграция с IdP, где нет OIDC, не покрывается.
  • Один инстанс — отказоустойчивость средствами БД, а не кластер приложения.
  • Мобильные приложения вне сторов — APK/DMG/IPA распространяются из GitHub Releases.
  • Молодой продукт — библиотека готовых интеграций меньше, чем у Мультифактора.

Итог: Ligament закрывает нишу «нужен свой MFA без облака и без enterprise-бюджета» — SMB, сервис-компании, инфраструктура на любом RADIUS-оборудовании, изолированные контуры. Enterprise/гос — за сертифицированными аналогами.
